# Task 98 — Pagina Sincronizzazione, cronologia e ripristino (v0.46.0)

Quarta task del piano. Due commit: livello dati (`listRemoteHistory`, `loadHistoryBackup`, `restoreFromBackup`)
e interfaccia.

## Fatto
- Pagina `/sincronizzazione` su mobile (`SincronizzazioneScreen`) e desktop (`DesktopSincronizzazioneScreen`), stesso
  path nei due router (nessuna voce in `translatePath`). Voce nel menu "Gestisci" (mobile) e nella barra laterale
  (desktop); `navTransition` la tratta come pagina del menu.
- La configurazione di sync è stata SPOSTATA dalle Impostazioni (mobile e desktop) alla nuova pagina, con un link.
  Stato e azioni stanno in `useGitSyncSettings` (condiviso).
- Cronologia: commit del file dei dati + file in `backups/` + copie di sicurezza locali (`buildHistoryItems`), ordinate
  per data. Anteprima del diff contro i dati di adesso (`useHistoryPreview` → `diffBackups` + `summarizeDiff`,
  `SyncDiffView`) e ripristino con conferma (`useRestore` → `restoreFromBackup`).
- Ripristino = UN commit nuovo sopra la cronologia (mai force) con i dati ripristinati + backup di locale e/o remoto
  non ancora sincronizzati; bloccante. Le copie di sicurezza locali si ripristinano solo in locale.
- Guida a sette accordion (`<details>`, chiusi all'inizio).
- Testi aggiornati: la conferma del "Scarica da remoto" non dice più "non si può annullare".
- Stili comuni delle schede desktop estratti in `settingsUi.tsx` / `settingsStyles.ts`.
- Test al 100% per `historyItems`, `diffSummary`, `syncBackup.parseBackupPath`, e per history/restore in `gitSync`.
