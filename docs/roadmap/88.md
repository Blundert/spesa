# Task 88 — Desktop: tutte le pagine, ordinamento, anno, colori (v0.40.0)

Seguito di `87.md`. Richieste: colonne ordinabili nelle tabelle, impostazioni complete, Catalogo ordinabile
per prezzo/nome/categoria, Statistiche a colori, anno nelle date, euro per i supermercati in Dashboard,
tutte le pagine mobile mancanti su desktop.

## Fatto
- **Fondamenta**: `src/lib/sortRows.ts` (+ test, in coverage), `SortableTable`, `Modal`, `PageHeader`,
  `chartColors.ts`; `formatDate` e `formatWeekLabelWithYear` in `src/lib/date.ts` (+ test).
- **Router/menu desktop**: tutte le rotte (stessi path del mobile, tranne Lista `/lista` e statistiche `/stats`),
  sidebar a gruppi, pulsante "Inizia la spesa" con riepilogo settimana (`NewShoppingModal`).
- **Pagine nuove** (schermate desktop vere, stessi hook/repository del mobile): Lista, Liste, Dettaglio articolo,
  Pasti (griglia settimanale), Pianificazioni, Piatti, Supermercati, Novità, Spesa in corso, Dettaglio spesa.
  `Impostazioni` ora ha tutte le impostazioni del mobile (sync GitHub, azzera dati, tutorial, debug…).
- **Tabelle ordinabili** in Storico, Catalogo, Statistiche, Supermercati, Liste, Piatti, Pianificazioni, Spesa,
  Dettaglio spesa, Dettaglio articolo.
- **Colori**: palette dei grafici in `chartColors.ts` (blu totale, verde buoni, arancione di tasca, serie
  categoriche). Deviazione dal mockup (grigio) richiesta esplicitamente dall'utente; il resto della UI resta neutro.
- **Dashboard**: importi in euro accanto alle barre dei supermercati.
- Lavoro suddiviso fra più agenti su file distinti; il mobile non è stato toccato (verificato con `git status`).

## Scelte non specificate (opzione più semplice)
- Su desktop i bottom sheet diventano `Modal` centrati; `PriceKeypad` è sostituito da un campo importo che
  accetta calcoli (`src/lib/amountInput.ts`).
- Non portati: tutorial/tour guidato, animazioni di transizione tra pagine, overlay a schermo intero della

spesa in corso → importo con calcolo → fine spesa → Storico, Supermercati, Piatti, Catalogo (ordine per prezzo) →
dettaglio articolo, Impostazioni (import con Modal).

categorie della Lista su una sola colonna, "€" mancante in alcuni totali, etichetta "spesi" da sola,
nessun link di ritorno nel dettaglio spesa.
