# Task 78 — Feat: Storico con totale calcolato e scarto dello scontrino (v0.33.0)

## Richiesta

Nella lista dello Storico mostrare anche il prezzo calcolato dai valori degli
oggetti e lo scostamento percentuale rispetto al totale confermato. L'utente ha
scelto la variante **B** tra tre mockup (A riga sotto il totale, B calcolato a
sinistra + etichetta colorata, C testo descrittivo).

## Implementazione

- `budgetSelectors.ts`: `receiptDeviationPercent(confirmed, computed)` =
  (confermato − calcolato) / calcolato, arrotondato a un decimale; `null` se la
  somma degli oggetti è 0. Positivo = scontrino più alto degli oggetti.
- `money.ts`: `formatSignedPercent` → "+4,4%", "−3,3%" (U+2212), "0%"; virgola
  decimale come gli importi, ",0" finale rimosso.
- `StoricoScreen` / `SessionCard`:
  - riga grigia "data · N oggetti · calc. €X" (chiave `storico.computed`);
  - sotto il totale grande, etichetta con lo scarto: arancione (`#FBEDE4`/`#C2612A`)
    se lo scontrino è più alto, verde (`#E6F2EA`/`#3B8A57`) se più basso, grigia se 0%.
  - Calcolato ed etichetta solo con totale confermato e somma oggetti > 0 (niente per
    le spese "Non completata", le vecchie senza conferma e quelle con 0 oggetti).
- Test: `receiptDeviationPercent` e `formatSignedPercent` (coverage 100%).

## Verifica

- Browser con dati reali: oggetti €27,55, scontrino €28,80 → "calc. €27,55" e
  "+4,5%" arancione; sessione con conferma uguale → "0%" grigio; Lidl con 0 oggetti
  → nessun "calc.".
