# Task 77 — Feat: svuota tutta la lista (v0.32.0)

## Richiesta

Un bottone per svuotare tutta la lista della spesa.

## Implementazione

- `listItems.ts`: `clearList()` → `db.listItems.clear()`. Rimuove solo le voci di
  lista: item del catalogo, prezzi, acquisti e sessioni restano.
- `useListItems.ts`: `useClearList()` (refetch di `qk.listItems()`, come le altre
  mutazioni della lista).
- `ListaScreen`: "Svuota" in alto a destra accanto al titolo (stesso stile di
  "Storico" in Pasti), visibile solo con lista non vuota. Apre uno sheet di
  conferma (stesso schema di "Rimuovere dalla lista?": titolo rosso, bottone rosso,
  "Annulla") con il numero di oggetti; alla conferma toast "Lista svuotata".
- i18n: `lista.clear`, `clearConfirmTitle`, `clearConfirmBody`, `clearConfirm`,
  `cleared` (it + en). Frase unica senza plurali (l'app non usa i plurali i18next).
- Test: `src/db/repositories/listItems.test.ts` (svuota lista mantenendo il catalogo;
  lista già vuota).

## Scelte non specificate

- Conferma obbligatoria (azione distruttiva), nessun "annulla" dopo lo svuotamento.
- Durante una spesa in corso, svuotare la lista non tocca il carrello (gli acquisti
  della sessione restano).

## Verifica

- Browser: lista vuota senza bottone → 3 oggetti → "Svuota" → conferma con "(3)" →
  "Svuota lista" → toast, lista vuota, bottone sparito.
