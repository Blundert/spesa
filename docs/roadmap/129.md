# Task 129 — F8: nessun comando di modifica nella spesa di un altro (1.4.8)

## Causa
Per le spese altrui (`foreign`) il dettaglio avvolgeva tutto in un contenitore `pointer-events: none`: i link "Modifica importo / data / buoni" restavano visibili (sottolineati, con il cursore giusto) ma il clic non passava. Su desktop compariva anche "Di tasca tua" con l'importo dell'altro.

## Fatto
- `SessioneScreen` (mobile): data, totale e buoni sono testo semplice se la spesa è di un altro (niente sottolineatura, niente `input` data).
- `DesktopSessioneScreen`: i link di modifica non vengono renderizzati se `foreign`; la scheda "Di tasca tua" nemmeno.
- Il contenitore `pointer-events: none` resta per la tabella degli acquisti. Smoke (Flusso 49.4). Versione 1.4.8, changelog, badge README. Componenti non coperti dai test unitari: verifica nel browser a fine lavoro.
