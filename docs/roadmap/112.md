# Task 112 — Fix: "collega GitHub" anche da collegati (1.1.2)

Segnalazione: creando una lista condivisa l'app chiedeva di collegare GitHub, ma in Impostazioni risultava collegato.

## Causa
La sezione Condivisione considerava "collegato" solo chi aveva token **e** login GitHub. Il login si salva dal flusso "Collega GitHub" (task 2):
chi aveva già inserito il token a mano non lo aveva.

## Fatto
- `isGithubConnected()` ora guarda solo il token.
- `sharedLists.connection()` (asincrona) ricava il login da `/user` quando manca e lo salva; 401/403 → "collega prima GitHub".
- La pagina Sincronizzazione ricorda il login anche per un token già salvato quando lo verifica.
- Test al 100%; versione 1.1.2, changelog, badge, `test/smoke.md` (Flusso 52).

## Da sapere
- Un token **fine-grained** (quello tipico del backup, limitato a un repo) non può creare repository né invitare: darà "Il token non ha il permesso di farlo".
  Serve il token classico con permesso `repo` ("Crea token su GitHub" in Sincronizzazione).
