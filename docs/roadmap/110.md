# Task 110 — Rifiniture e versione 1.1.0

Ultima task del piano "liste condivise". Mobile e desktop insieme.

## Fatto
- **Accesso perso** (403/404 durante la sync): la riga di stato dice "Non hai più accesso a questa lista condivisa", il polling
  si ferma (errore non recuperabile) e compare "Tieni come lista normale", che scollega lasciando la lista e gli articoli
  com'erano (`SharedSyncStatus`, mobile e desktop). Il repo non viene toccato.
- **Backup e ripristino** (già coperti da test nelle task 1 e 3): il backup porta il collegamento ma mai il token né `lastSha`;
  dopo un ripristino la prima sync scarica e unisce senza scrivere. Verificato anche nel browser nelle task precedenti.
- **Versione 1.1.0**: `package.json`, `package-lock.json`, badge dei README e **un'unica** entry `'1.1.0'` in `src/data/changelog.ts`
  (it/en) che racconta tutta la feature (come deciso: niente bump nelle task intermedie).
- README (it/en): voci per backup/cronologia e per le liste condivise.
- `CLAUDE.md`: sezione "Liste condivise" con le regole da tenere (scritture dai repository, `uncounted` nei calcoli, prima sync
  che non scrive, CSP e domini esterni).
- `test/smoke.md`: Flusso 50.

## Verifica finale
Test (677) al 100% di statement/branch/function/line, `tsc` (app e node), `eslint src` e `npm run build` puliti. Provato nel browser
sul build di produzione con GitHub simulato: accesso perso e "Tieni come lista normale" a 390 px.

## Da sapere / non provato
- **Mai provato contro GitHub vero né con due dispositivi reali**: tutto il lavoro è stato verificato con test unitari e con un
  GitHub simulato in Playwright. Da provare a mano prima di fidarsene: creazione del repo, invito e accettazione, primo file in un
  repo vuoto, `PUT contents` con branch di default diverso da `main`.
- Il token classico `repo` dà accesso a tutti i repository privati dell'utente: mitigato da CSP, scadenza consigliata e
  "Dimentica il token", ma è una scelta di sicurezza da riconsiderare (account GitHub dedicato).
- La scadenza del token non si può precompilare né verificare dall'app (la guida dice di lasciare 30 giorni).
- Limiti noti, già nei dump delle singole task: una spesa pubblicata non si aggiorna se la modifichi; un dispositivo fermo più di
  30 giorni può far ricomparire voci o spese eliminate; il polling vale solo con la lista (o la spesa) aperta.
