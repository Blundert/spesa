# Task 101 — Grafo dei commit con diff affiancato, solo desktop (v0.49.0)

Settima e ultima task del piano. **Solo desktop**, come deciso nel piano: su mobile restano l'elenco della cronologia
(task 4) e il confronto per tabella.

## Fatto
- `commitGraph.ts` (puro, 100%): `layoutGraph(commits, heads)` mette i commit in corsie e dice per ogni riga quali
  linee disegnare (`incoming`, `through`, `outgoing`) e quali branch hanno la punta lì. Ordine topologico (figli prima
  dei genitori) anche con orologi sfasati; storia tagliata e unioni a più genitori gestite.
- `gitSync.listCommitGraph()`: gli ultimi 100 commit di ogni branch (tutti, non solo quelli che toccano il file dei
  dati), deduplicati, con genitori e punte dei branch.
- Desktop, pagina Sincronizzazione: scheda "Grafo dei commit" (`CommitGraph`, SVG con i colori di serie del tema
  via `seriesColor`) e finestra `CommitModal`: diff affiancato (`SideBySideDiff`, prima/dopo per tabella) rispetto al
  commit precedente o ai dati di adesso, e ripristino con conferma (`useRestore`, via repo).
- `useCommitGraph` / `useCommitDiff`: il commit senza file o senza genitore si confronta con un backup vuoto.
- Test al 100% (`commitGraph`, `listCommitGraph`); `FakeGithub` conosce genitori e commit di tutti i branch.

## Verifica nel browser
1280 px con GitHub simulato (due branch, un'unione): corsie, etichette dei branch, diff affiancato sui dati reali.
Non provato contro GitHub vero né con storie molto lunghe.

## Scelte / da sapere
- Nessuna paginazione: si vedono gli ultimi 100 commit per branch.
- I valori nel diff affiancato mostrano i nomi dei campi così come sono (es. `priceCents`), con date e importi formattati.
- Il grafo non si aggiorna da solo dopo un'azione: ricarica la pagina o usa "Sincronizza ora".
- Con questa task il piano è completo: backup della scelta scartata, auto-sync desktop, motore di diff, pagina
  Sincronizzazione con cronologia e ripristino, unione per gruppi, branch, grafo.
