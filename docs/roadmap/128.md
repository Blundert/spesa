# Task 128 — F1: la finestra di modifica lista si aggiorna dopo Condividi (1.4.7)

## Causa
Nella pagina Liste (desktop `DesktopListeScreen`, e mobile `ListeScreen`) la lista in modifica è una COPIA salvata al clic (`setEditing(l)`). `ShareSection` riceveva quella copia e non vedeva il collegamento creato da "Condividi". Dalla pagina Lista (lista "viva") funzionava: per questo sul mobile il difetto non si era visto nel run e2e.

## Fatto
- `ListEditSheet` (mobile) e `ListEditModal` (desktop): `liveList` letta da `useShoppingLists()` per id (con ripiego sulla copia) e passata a `ShareSection`. Tutto il resto del modulo resta sullo stato del form.
- Nessun test unitario (componenti React non coperti): verifica nel browser a fine lavoro. Smoke (Flusso 47.2bis). Versione 1.4.7, changelog, badge README.
