# Task 102 — Sicurezza: CSP, mockup fuori dal deploy, "Dimentica il token" (nessuna versione)

Prima task del piano "liste condivise". Serve a restringere il danno possibile se il token GitHub (salvato in chiaro
nel `localStorage`) venisse rubato, **prima** di allargarne i permessi con il token classico. Come deciso nel piano:
nessun bump di versione né changelog (confluiscono nella entry 1.0.0).

## Fatto
- **Mockup fuori dal deploy.** `public/spesa-design.html` + `public/support.js` caricavano React e Babel da unpkg.com
  nella stessa origine dell'app, quindi con accesso al token. Restano in `public/` (il dev server li serve ancora), ma il
  plugin `hardened-production` di `vite.config.ts` li toglie da `dist/` e `workbox.globIgnores` li esclude dal precache
  del service worker.
- **CSP via `<meta>`**, solo nel build di produzione (in dev Vite usa script inline e websocket): `src/lib/csp.ts`
  (`buildCsp`, puro, 100%). `script-src 'self'` + hash sha256 dello script inline del tema (calcolato dal plugin sull'HTML
  finale, un hash per script), `connect-src 'self' https://api.github.com`, `object-src 'none'`, `base-uri`/`form-action`
  `'self'`. `style-src` tiene `'unsafe-inline'` (attributi style di React, Vaul, Sonner, Recharts); `img-src` ammette
  `data:` e `blob:` (tessere fedeltà). `dist/404.html` eredita il meta perché è la copia di `index.html`.
- **"Dimentica il token su questo dispositivo"** in Sincronizzazione, mobile e desktop: `forgetGitToken()` svuota solo il
  token e lascia owner/repo/branch/file; toast `settings.syncTokenForgotten`. Disattivato senza token. Stringhe in
  `it.ts` ed `en.ts`.
- Test al 100%: `csp.test.ts` e il caso `forgetGitToken` in `gitSync.test.ts`; `csp.ts` aggiunto a `coverage.include`.
- `test/smoke.md`: nuovo Flusso 45.

## Verifica
`vitest --coverage` 100%, `tsc` (app e node), `eslint src` e `npm run build` puliti. Build di produzione provato con
`vite preview` in Playwright a 390, 800 e 1280 px: nessuna violazione CSP, service worker registrato, tema applicato,
chiamate ad `api.github.com` ammesse (401 con token finto), pulsante funzionante su entrambe le interfacce.
Non provato: installazione come PWA su iOS/Android, né sync con un GitHub vero con la CSP attiva.

## Scelte / da sapere
- **Ogni nuovo dominio esterno va aggiunto in `src/lib/csp.ts`**, altrimenti in produzione viene bloccato (in dev no).
  Rilevante per le prossime task: le chiamate restano su `api.github.com`.
- Su GitHub Pages non si possono impostare header: `frame-ancestors` e `report-uri` non funzionano nel meta e non sono
  stati messi.
- `workbox.runtimeCaching` per Google Fonts è ormai inutile (l'app usa il font di sistema e la CSP non li ammette):
  lasciato com'è per non uscire dallo scopo; si può togliere in una pulizia.
- Un caricamento diretto di un URL interno (es. `/sincronizzazione`) a onboarding concluso riporta a `/`: è già così nel
  build di prima di questa task (verificato su HEAD), non l'ho toccato.
- Restano da fare, nelle task successive, la validazione del file remoto (task 3) e la scadenza del token nel link
  precompilato (task 2).
